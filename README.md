# Linu Farol

GitHub Actions confere as páginas, os preços e o visual e entrega na VM (`deploy/ORACLE.md`). O `/identidade` leva para
https://familia.linupedia.com.br/identidade.

Montado com `linuarquivos/modelos/ferramentas/novo-irmao.py`. Antes de desenhar: o `IDENTIDADE.md` (o objeto e a cor
deste site) e o `IDENTIDADE-LINU.md` do linuarquivos.
